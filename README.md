# Men's Accessories Store

A simple Python-based backend project developed for the Programming Fundamentals course at FAST-NUCES.

## About the Project
This project is a basic store management system that allows an admin to manage men's accessories and customer orders through a terminal-based menu.

## Features
- Admin Login
- View Products
- Search Products
- Add New Products
- Update Product Details
- Place Customer Orders
- View Orders
- Generate Sales Reports

## Technologies Used
- Python
- CSV Files
- Jupyter Notebook

## Data Storage
The project uses two CSV files to save information:

- `products.csv` – Stores product details such as name, category, price and stock.
- `orders.csv` – Stores customer orders, quantities and total amounts.

## How to Run
1. Download or clone this repository.
2. Open the `.ipynb` file in Jupyter Notebook or Google Colab.
3. Run the notebook cells from top to bottom.
4. Use the admin login to access the menu.
